## 1. 한 것
| 항목 | 내용 |
|---|---|
| fallback MGP 곡선 | 모든 모델 후보가 탈락하면 목표 샘플(MGP)까지 이어지는 곡선을 만들어 같은 검사로 확인하고, Nav2 경로 앞부분/호와 같은 선택기로 고른다. 형태 9가지 중 통과한 것 중 벽에서 가장 먼 것(`mgp_fallback_shape_search`). 코드 기본값 꺼짐, 시험 설정에서 켬 |
| 후보 결정 창 | 결과 세 가지(검사 통과/탈락/선택·발행)만, 표 위는 `모델 선택`만, 최대 5행. fallback 행도 `C번호`(중복 없음), 통과했지만 못 뽑힌 fallback은 `선택 경로보다 총비용이 높음`, 이전/대체/복구 경로가 이기면 그렇게 표시 |
| RViz | 노란 GP 구 제거. 연두 = 모델 단계 선택(통과·적격 후보 중 총비용 최소) 1개, 후보가 없으면 선택된 fallback. 발행된 이전/복구 경로는 흰색. 빨강 선 최대 2. 후보 세트는 MGP 도달 때까지 유지(단, 연두 선택이 없는 세트는 바로 교체) |
| `never_hold` | 경로 계획 실패 시 빈 경로 대신 마지막 계획 경로의 남은 부분을 최대 6초, 로봇이 경로에서 0.6m 안일 때만 따라간다(그동안 후보 검사 없음). 센서 정지/도착/목표 대기는 그대로. odom/scan 허용 0.6/0.5초 → 1.0초 |
| 버그 | 시작 순간 로봇 위치 없음 → 선택 증거 오류 수정 |
